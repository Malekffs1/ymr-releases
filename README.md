# Android Release Files

This repository hosts versioned Android application packages and basic integrity information for published builds.

## Releases

Use the **Releases** section to find published builds. Each release should include its version, supported device architecture, SHA-256 checksum, and brief release notes.

## Verification

Before installing a package, verify its SHA-256 checksum against the value published with that release. Android updates can only install over an existing app when the package identity and signing certificate are compatible.

This repository does not contain application source code or signing keys.
